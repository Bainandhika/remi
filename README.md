# remi
Game web kartu remi kustom 1v3 melawan AI berbasis Vue.js &amp; Pinia. Kompetisi seru rebutan 1000 poin dengan mekanik unik: Joker dinamis, penalti awal, fitur "serok" tumpukan buangan, dan sistem "Salip-Sembelih" (skor reset ke 0 jika tersalip di atas 100 poin). Full client-side, ringan, taktis, &amp; seratus persen gratis!
